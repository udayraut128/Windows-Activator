# Windows-Activator
A Windows Activator is a tool used to activate Windows without a genuine product key. It bypasses Microsoft’s licensing system to unlock full features. Though commonly used, it’s illegal and risky, often containing malware, and may lead to system instability or lack of updates. Genuine activation is always recommended.



# Windows-Activator

**Windows-Activator** is a simple batch-based script that helps users activate various versions of Windows 10 without requiring a product key. It uses a KMS-based method to simulate activation and unlock all premium features.

> ⚠️ **Disclaimer:** This tool is intended for educational purposes only. Using unauthorized activation tools may violate Microsoft's terms of service. It is always recommended to use genuine product keys obtained legally.

## 📥 How to Use

Follow the steps below to use the Windows-Activator script safely:

1. **Clone or Download the Repository**
   - Click on the green `Code` button and select `Download ZIP`.
   - Extract the contents to any folder on your PC.

2. **Prepare the Activation Script**
   - Open **Notepad** or any plain text editor.
   - Open the file named `windows-activation.txt` from the extracted folder.
   - Copy all the code from this file and paste it into your new Notepad document.
   - Save the file with a `.bat` extension.  
     *(For example: `activate.bat`)*

3. **Run the Script as Administrator**
   - Right-click on the `.bat` file.
   - Select **Run as Administrator**.
   - The activation process will begin automatically.

4. **Important Note:**
   - Make sure your PC is **connected to your mobile hotspot** during activation.
   - Avoid using proxy networks, VPNs, or public Wi-Fi.

5. **Final Step**
   - After the process completes, **restart your PC** to apply changes.
